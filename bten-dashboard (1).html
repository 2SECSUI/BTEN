This is an independent, unofficial viewer built to read public Sui mainnet state for the BTEN package and coin type published in the linked repository. It is not affiliated with the repository's maintainers, holds no custody of funds, and signs no transactions. All figures come from live RPC calls made by your browser to Sui's public mainnet full node, or are explicitly marked as static repo claims.
