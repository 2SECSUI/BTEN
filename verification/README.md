# BTEN V16 verification artifacts

the deployed V16 package. It includes the source, compiled module, lockfile,
logo, and published-address data used by the repository build.

`0xc71c7ab810ba15ea337dc7722e8eaac4e3c7e631cf3557f70167783f1f3bcc41`;
its upgrade transaction is
`HckDUZGSTjyeLYtxn1we2NCg6DetjVXmcaeKbQ6p7b17`.

The V16 archive SHA-256 is
`7F9B668433BB62FD8C0594E18100C4413181C430298C7D9B3D1AFBC72497E165`.

runtime ledger.
